# 🌱 Primeiro Passo — Oportunidades para Começar

O **Primeiro Passo** é um site de impacto social desenvolvido para ajudar jovens e pessoas que estão iniciando sua trajetória profissional a encontrar oportunidades de emprego e se preparar para o mercado de trabalho.

A proposta é facilitar o acesso à informação, oferecendo orientações sobre estágios, programas de jovem aprendiz, preparação de currículo e desenvolvimento profissional.

## 🎯 Objetivo do Projeto

O projeto busca contribuir para a redução das dificuldades enfrentadas por quem procura o primeiro emprego, especialmente a falta de experiência profissional e de informações sobre como ingressar no mercado de trabalho.

## ✨ Funcionalidades

- **Apresentação do projeto:** explica o problema social e a proposta da plataforma.
- **Oportunidades profissionais:** apresenta opções para iniciantes, como estágios e programas de jovem aprendiz.
- **Dicas de preparação:** oferece orientações para o desenvolvimento profissional.
- **Formulário interativo:** coleta informações básicas e apresenta sugestões personalizadas para o próximo passo profissional.
- **Links externos:** direciona os usuários para plataformas de oportunidades e cursos.
- **Design responsivo:** adapta o layout para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, layout e responsividade.
- **JavaScript:** interatividade e lógica do formulário.

## 📂 Estrutura do Projeto

```text
Primeiro-Passo/
├── index.html
├── style.css
├── script.js
└── LEIA-ME.txt
```

- `index.html`: estrutura principal do site.
- `style.css`: estilos visuais, cores, espaçamentos e adaptação para dispositivos móveis.
- `script.js`: processamento do formulário e exibição de recomendações.
- `LEIA-ME.txt`: instruções para abrir e apresentar o projeto.

## 🚀 Como Executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo `index.html` em um navegador.
4. Explore as seções e teste o formulário interativo.

Não é necessário instalar dependências ou configurar um servidor para executar a versão básica do projeto.

## 🧪 Como Funciona o Formulário

O formulário utiliza JavaScript para identificar a situação profissional selecionada e apresentar uma sugestão inicial.

As recomendações variam conforme o perfil informado, como:

- **Estudante:** procurar estágios, projetos acadêmicos e cursos.
- **Em busca de emprego:** preparar o currículo e pesquisar vagas para iniciantes.
- **Mudança de área:** desenvolver habilidades e realizar cursos introdutórios.

**Observação:** o formulário é demonstrativo. Os dados não são enviados para um servidor nem armazenados. As recomendações são orientações iniciais, não vagas de emprego confirmadas.

## 🌍 Impacto Social

O acesso ao primeiro emprego pode ser um desafio para muitas pessoas. O Primeiro Passo procura tornar informações sobre oportunidades e preparação profissional mais acessíveis, incentivando o aprendizado e a autonomia de quem está começando.
